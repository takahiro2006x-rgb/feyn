# Feyn デザインのルール

Feynの画面（LP・アプリ・先生の画面）を作る・直すときは、このルールに従う。
元になっているのは LP（`landing.html`）。迷ったら LP の書き方を見る。

---

## 1. 世界観（核のモチーフ）

**「方眼ノートと赤ペン」**

- あなた（生徒）の説明＝方眼ノートに鉛筆で書いた文
- Feyn（あなたが教える生徒役）の質問＝赤ペンの書き込み
- 夜（ダークモード）は「夜の黒板」

モチーフは、読みやすさを壊さない範囲で効かせる。LPは方眼を背景にうっすら、赤ペンは要点だけ。
チャット画面は「罫線ノート」：会話の地に罫線と左の赤い余白線、Feynの質問は赤ペンの字（2026-11-05、淡白すぎたため3案から選んで強めた）。

---

## 2. 色

色は下のトークンだけを使う。CSSに色を直接書かない（`#58CC02` などを書かず、`var(--brand)` と書く）。

### トークン

| トークン | ライト | ダーク（夜の黒板） | 使い道 |
|---|---|---|---|
| `--paper` | `#FFFFFF` | `#131A16` | 紙。カード・吹き出し・入力欄の地 |
| `--paper-2` | `#F3F8FB` | `#18211B` | 淡い帯。ページの地、サイドバー、交互の帯 |
| `--grid-line` | `rgba(40,110,170,.085)` | `rgba(200,230,210,.06)` | 方眼の線（背景だけ） |
| `--rule` | `#D9E3EA` | `#2D3A31` | 罫線・枠線・区切り |
| `--ink` | `#1B2A33` | `#ECF1EC` | 文字（墨） |
| `--ink-soft` | `#4A5A66` | `#B8C4BA` | 補足の文字・ラベル（白地で 7:1 以上） |
| `--pencil` | `#33424D` | `#D5DED6` | 生徒が書いた文（手書き風の所） |
| `--red` | `#D4352A` | `#FF6B5E` | 赤ペン（下の「赤の決まり」） |
| `--red-dark` | `#A8261E` | `#FF8C82` | 赤いボタンの影・押したとき |
| `--board` | `#1E4D2B` | `#0E2416` | 黒板の緑。濃い帯・フッター |

| トークン | ライト | ダーク | 使い道 |
|---|---|---|---|

| `--note-rule` | `rgba(40,110,170,.13)` | `rgba(200,230,210,.08)` | ノートの罫線（32px間隔） |
| `--margin-line` | `rgba(212,53,42,.35)` | `rgba(255,107,94,.40)` | ノートの左の赤い余白線 |
| `--feyn-bubble` | `#FFFFFF` | `#1B241E` | Feynの吹き出し（ノートに貼ったメモ） |
| `--me-bubble` | `#FFFFFF` | `#1B241E` | 自分の吹き出し（自分で書いた説明のメモ） |
| `--hint-bg` | `rgba(242,183,5,.16)` | `rgba(242,183,5,.14)` | ヒント（蛍光ペンを引いたメモ） |
| `--answer-bg` | `rgba(30,77,43,.08)` | `rgba(120,200,140,.10)` | 答え（黒板の板書） |

### 赤の決まり

赤（`--red`）は次の2つにだけ使う。

1. **Feynからの質問**（赤ペンの書き込み・質問の要点の印）
2. **申し込み・決定のボタン**（無料で始める、送信、保存する など、その画面で一番押してほしいボタン1つ）

エラー表示は赤の文字で短く出してよいが、面（背景）を赤で塗らない。削除など危ない操作のボタンは、赤の**枠線**にして塗りつぶさない（決定ボタンと見分けるため）。

### 科目の色

科目ごとの色（物理は青、数学は紫…）は、**小さな印（点・下線）にだけ**使う。ボタンや吹き出しを科目の色で塗らない。

## 3. 文字

| 用途 | フォント | 太さ |
|---|---|---|
| 本文・UI | `"Zen Kaku Gothic New", "Hiragino Sans", "Yu Gothic", sans-serif`（`--sans`） | 500（本文）・700（ラベル・強調）・900（見出し・数字） |
| 手書き（赤ペン・鉛筆の雰囲気） | `"Klee One"`（`--hand`）600 | 小さな書き込み・凡例だけ。本文や長い文には使わない |

大きさは次の段から選ぶ（px）:

| 段 | 大きさ | 使い道 |
|---|---|---|
| caption | 12 | 注記・時刻・小さなラベル |
| small | 14 | ボタンの文字、補足、サイドバーの項目 |
| body | 16 | 本文、吹き出し、入力欄（スマホの入力欄は必ず16以上。iOSが拡大してしまうため） |
| lead | 18 | 導入文、カードの見出し |
| title | 20〜24 | 画面・セクションの見出し |
| display | LPの見出しだけ `clamp()` で大きく | |

- 行の高さ: 本文 1.75〜1.85、見出し 1.3
- 日本語の折り返し: 見出し・短い文は `word-break: auto-phrase`（文節で折り返す）
- 文字の強弱は「太さと色（`--ink` / `--ink-soft`）」で付ける。大きさの段を増やさない

## 4. 余白・角の丸み・影

### 余白（段）

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 72 / 96`（px）。これ以外の数を使わない。

- 部品の中: 8〜16
- 部品どうし: 12〜24
- セクションの上下: PC 96、スマホ 52〜72

### 角の丸み（段）

| 段 | 大きさ | 使う所 |
|---|---|---|
| `--r-sm` | 4px | カード、入力欄、表、ノート（紙は角張っている） |
| `--r-md` | 6px | ボタン |
| `--r-lg` | 12px | 吹き出し |
| `--r-pill` | 999px | 小さなタグ、進み具合のバー |

アイコンの丸（アバター）は 50%。端末の枠（LPのスマホのイラスト）だけは例外。

### 影（4種類だけ）

| 名前 | 値 | 使う所 |
|---|---|---|
| 紙 | `0 12px 30px rgba(27,42,51,.10)` | 浮かせたいカード（ノート・結果の画面） |
| 重なり | `0 18px 40px rgba(27,42,51,.16)` | ダイアログ・メニューなど、上に重なるもの |
| 判子 | `0 4px 0 var(--red-dark)` | 赤い決定ボタンだけ（押すと沈む） |
| メモ | `0 2px 10px rgba(27,42,51,.07)`（`--shadow-note`） | チャットの吹き出し（ノートに貼ったメモ） |

枠線は `1px solid var(--rule)`。太い枠（2px以上）は、強調したい1か所だけ。

## 5. 部品の基本の形

### ボタン

| 種類 | 形 |
|---|---|
| 決定（赤） | 赤の塗り・白文字・角6px・判子の影。最低の高さ 48px（大きいもの 56px）。1画面に1つ |
| 普通 | `--paper` の地・`--rule` の枠・`--ink` の文字・角6px。高さ 44px 以上 |
| 控えめ | 枠なし・`--ink-soft` の文字。ヒントのように「押せるが主張しない」もの |
| アイコンだけ | 44×44px 以上。必ず `aria-label` を付ける |

押したときは少し沈む（`translateY(1〜3px)`）。光る・跳ねるような動きはしない。

### 吹き出し（チャット）

会話の地は `--note-paper` に罫線（`--note-rule`）と、左の赤い余白線（`--margin-line`）。Feynのアイコンは余白線の左、吹き出しは右。

- **Feyn（左）**: `--feyn-bubble` の地・左に3pxの赤い線（赤ペン）・右側だけ角 12px・メモの影・左にFeynのアイコン。最後の質問の文は赤ペンの字（`--red`・太字）に、薄い赤の蛍光ペン
- **自分（右）**: `--me-bubble` の地・`--rule` の枠・角 12px（右上だけ 4px）・メモの影・文字は `--pencil`・アイコンなし
- ヒント: `--hint-bg`＋左の線は蛍光ペンの黄、答え: `--answer-bg`＋左の線は黒板の緑
- 文字は 16px・行の高さ 1.75。数式・画像・長い英単語ははみ出さない（`overflow-wrap: anywhere`、数式は横スクロール）

### カード

`--paper` の地・`--rule` の枠・角 4px。浮かせるときだけ「紙」の影。

### 入力欄

`--paper` の地・`--rule` の枠・角 4px・文字 16px。フォーカスしたら枠を `--ink` にし、外側にフォーカスの輪（下）を出す。

### フォーカス

`:focus-visible { outline: 3px solid var(--red); outline-offset: 3px; }` を全画面で使う。消さない。

## 6. 動き

- 動きは短く（0.2〜0.6秒）、意味のある所だけ（赤ペンで書き込む、バーが伸びる）
- アプリでは、丸い判子（「納得！」の丸など）の演出は使わない（2026-11-05、野暮ったく見えるため外した）。クリアは納得度バーと短い紙吹雪で伝える
- `prefers-reduced-motion: reduce` の人には動きを出さない。JSが動かないときも全部見える状態を初期値にする
- 常に動き続けるもの（キラキラ・ふわふわ浮く）は使わない

---

## 7. やってはいけないこと

- 色を増やす（新しい色相を足す、科目の色で面を塗る、紫・オレンジなどを「アクセント」に使う）
- 赤を、Feynの質問と決定ボタン以外に使う
- 角の丸みや影をバラバラにする（12px・14px・16px・20px が混ざる、など）。段から選ぶ
- 太い枠線と立体の影を、あちこちに付ける（全部が「押せそう」に見えて、何が大事か分からなくなる）
- 絵文字に頼る（ボタンの頭に毎回絵文字を付ける、見出しを絵文字で飾る）。アイコンが要るときは線のアイコン（SVG）を使い、文字のラベルを必ず付ける
- 小さすぎる文字（12px未満）、薄すぎる文字（白地で 4.5:1 未満）
- フォーカスの輪を消す
- 手書き風フォント（Klee One）を本文に使う

## 8. 今のアプリとのずれ（2026-11-05 時点）

全部の画面（チャット・マイページ・ログイン・先生の画面・特商法・規約）を、このルールにそろえた（`docs/chat-redesign/REPORT.md`・`docs/pages-redesign/REPORT.md`）。
トークンは `theme.css` の1か所にあり、全部の画面が読み込む。新しく画面を作るときも `theme.css` を読み込み、チャット画面の `style.css` やマイページの書き方を手本にする。

まだ残っているずれ:

| ずれ | 場所 |
|---|---|
| PWAの色が以前の緑（`#58CC02`）のまま | `manifest.json` の `theme_color`・`background_color`、`icons/` |
| 置き換えで直したため、使っていない古い指定が少し残っている | `dashboard.html`・`student_detail.html` の `<style>` |
| `theme.css` の「古いページの変数名」（`--bg`・`--card` など）を、まだ先生の画面が使っている | `dashboard.html`・`student_detail.html` |
