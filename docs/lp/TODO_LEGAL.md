# 公開前に埋める項目（利用規約・プライバシーポリシー・特商法の表記）

ここには「何を書けばいいか」だけを書いています。中身は決めて書き込んでください。
法律の専門家の確認を受けてから公開してください。

- 利用規約・プライバシーポリシーは `docs/drafts/*.md` を直し、`py scripts/build_legal_pages.py` でページに反映する
- 特商法の表記は `tokushoho.html` を直接直す
- 全部埋まったかは `py scripts/check_before_deploy.py` で確かめる（終了コード0になればOK）
- 最後に、各ページ冒頭の「下書き・公開前に要確認」の注意書きを外す
  （規約・ポリシーは `docs/drafts/*.md` 冒頭の「> 」で始まる行と、`scripts/build_legal_pages.py` の黄色い枠。特商法は `tokushoho.html` の「雛形です」の枠）

## 特定商取引法に基づく表記（`tokushoho.html`）

| 項目 | 何を書くか |
|---|---|
| 販売事業者 | 事業をしている人・会社の名前。個人事業なら本名 |
| 運営統括責任者 | 運営の責任者の名前。販売事業者と同じなら「同上」 |
| メールアドレス | お客様からの問い合わせを受けるアドレス（返信できるもの） |
| 所在地・電話番号 | 今は「請求があれば遅滞なく開示」。個人事業でこの書き方でよいか、念のため確認する |

## 利用規約（`docs/drafts/terms_of_service.md`）

| 項目 | 何を書くか |
|---|---|
| 事業者名（冒頭） | 規約を定める事業者の名前（特商法の「販売事業者」と同じにする） |
| 第2条 未成年の登録 | 何歳未満は保護者の同意が必要か、同意をどう確かめるか（例: 登録画面のチェック欄） |
| 第4条 自動更新 | 受験生プランが自動で更新されること、いつ更新されるか（例: 申し込んだ日から1か月ごと） |
| 第4条 返金 | 支払い済みの料金を返金するか、しない場合の例外 |
| 第7条 サービス終了 | 有料プランを終えるとき、何日前に知らせるか、支払い済みの料金をどう扱うか |
| 第10条 責任の上限 | 損害が出たとき、どこまで責任を負うか（消費者契約法で無効になる書き方があるので専門家に確認） |
| 第12条 管轄裁判所 | 争いになったときの裁判所（例: 事業者の住所を受け持つ地方裁判所） |
| 制定日 | 公開する日 |

## プライバシーポリシー（`docs/drafts/privacy_policy.md`）

| 項目 | 何を書くか |
|---|---|
| 事業者名（冒頭・11） | 個人情報を扱う事業者の名前 |
| 3 未成年の利用者 | 何歳未満は保護者の同意が必要か、という方針 |
| 3・10 お問い合わせ窓口 | 保護者からの削除依頼や、開示・訂正の請求を受ける窓口（メールアドレスなど） |
| 5 Render・Supabase のリージョン | サーバーとデータベースがどの国・地域にあるか（各サービスの管理画面で確認できる） |
| 5 外国への提供 | 外国の事業者（Google・Groq・Stripe など）にデータを渡すことについて、同意をどう取るか、相手の国の制度や保護の仕組みをどう知らせるか |
| 6 AIサービスへの送信 | 実際に使うAIの提供元と料金区分、送ったデータがどう扱われるかを、利用者と保護者に分かる言葉で（18歳未満の利用についての規約の問題が決まってから） |
| 7 Stripe 上のデータ | 決済の記録が Stripe にどのくらい残るか、消してほしいときの依頼方法 |
| 8 安全管理 | データベースに誰がアクセスできるか、バックアップをどうしているか |
| 11 連絡先 | 問い合わせ用のメールアドレス |
| 12 改定の知らせ方 | ポリシーを大きく変えるとき、どう知らせるか（例: ログイン時に表示して同意を取る） |
| 制定日 | 公開する日 |

## LP（`landing.html`）・設定

| 項目 | 何を書くか |
|---|---|
| `CONTACT_EMAIL`（Render の Environment） | 塾・学校の先生から導入の相談を受けるメールアドレス。未設定ならLPは「準備中」 |
| 使った人の声 | 実際の利用者から掲載の許可をもらった声。入れたら `data-placeholder` を消す |
| og:url・og:image・canonical | 独自ドメインにしたら、`landing.html` の3か所のURLを書き換える（今は `feyn-28kg.onrender.com`） |
