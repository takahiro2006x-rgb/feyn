## 6. AIサービスへの送信について（重要）

Feynとの会話の内容と、アップロードした写真は、回答を作るために Google の Gemini API に送信されます。

- **Gemini API の無料枠を使う場合**: Google の規約上、送信した内容と回答は Google の製品改善や機械学習技術の開発に使われ、人が読んで確認することがあります。未成年の学習の記録を送ることになるため、**本番では有料枠（送信内容が製品改善に使われない区分）を使うことを強く推奨します。**
- **Gemini API の有料枠を使う場合**: Google の規約上、送信した内容は製品改善には使われず、不正利用の検知と法令対応のために一定期間だけ記録されます。
- **年齢についての規約**: 2026-10-25 時点の Gemini API 利用規約には、18歳未満の人が使う可能性の高いサービスでは利用しない、という条件があります。公開前に、提供元の変更または Google との確認が必要です（`OVERNIGHT_REPORT.md` 参照）。

【決定後に書き換え: 実際に使う提供元・料金区分・データの扱いを、利用者（と保護者）に分かる言葉で記載する】

会話の中には、名前・学校名・住所などの個人情報を書かないよう、利用者にお願いします。

## 7. 保存期間と削除

- アカウントと学習の記録は、アカウントを削除するまで保存します。
- マイページの「アカウントの削除」から、本人のデータ（会話・学習の記録・苦手ノート・課題の記録・利用状況の記録・アカウント）をすべて削除できます。削除したデータは元に戻せません。
- 有料プランの契約中は、先に解約していただく必要があります。
- 決済サービス（Stripe）上の顧客情報・請求の記録は、会計・税務上の必要から、Stripe 上に残ります。【保存期間と削除依頼の方法を記入】
- AIサービスの提供元に送信済みのデータは、各提供元の規約に従って扱われ、当方からは削除できません。

## 8. 安全管理

- パスワードと秘密の質問の答えは、復元できない形（ハッシュ）で保存します。
- 通信は暗号化（HTTPS）します。
- ログインの失敗が続いた場合は、一定時間ログインを制限します。
- 【データベースのアクセス権限の管理・バックアップの方針を記入】

## 9. Cookie・端末への保存

- ログイン状態を保つために Cookie を使います（最長30日間）。
- ダークモードなどの表示設定と、お知らせを表示済みかどうかを、お使いの端末（ブラウザ）に保存します。これらは当方のサーバーには送られません。
- 広告・行動追跡目的の Cookie は使用していません。
