# チャット画面の診断（改善前）

撮影: 2026-11-05、`py scripts/lp_shots.py chat docs/chat-redesign/before`
（使い捨てのSQLite・デモ生徒A・AIは台本。物理・運動量の会話を4往復し、ヒントを表示した所／Feynが納得して結果が出た所／写真モードの始まり。スマホ375×812・PC1280×800、ライト・ダーク）

スクリーンショット: `docs/chat-redesign/before/`（`sp|pc`-`light|dark`-`chat|clear|photo`.png）

## 野暮ったく見える原因

### 1. 色が多く、科目の青が画面じゅうを塗っている
- 物理を選ぶと、科目のボタン・科目のバッジ・Feynのアイコン（全部の吹き出しの横）・自分の吹き出し・納得度バー・送信ボタンが、すべて同じ青（`#3B82F6`）で塗られる。科目が変わると紫・オレンジ…と全部が入れ替わる。
- そこに、ヒントの黄、答えの水色、結果の理解度の黄・オレンジ、レベルのバッジの色（6色）、ロゴの緑が加わる。`style.css` だけで直書きの色が30種類。
- LPは「白・墨・赤ペン・黒板の緑」でまとまっているので、LPから来ると別のアプリに見える。

### 2. 何もかもが「押せるボタン」に見える
- 吹き出し・アイコン・科目・バッジに、立体の影（`0 4px 0` 〜 `0 8px 0`）と 2px の太い枠が付いている。押せないものまで浮いていて、どこが大事か分からない。
- 角の丸みが 4・10・12・14・16・20・24・99px とバラバラ。

### 3. 文字に強弱がない
- 吹き出しの本文も、ラベルも、ボタンも、ほぼ全部が太字（700〜800）。長いFeynの質問が「太字の塊」になって読みにくい。
- 補足の文字（`--subtext: #AFAFAF`）は白地で約2.3:1しかなく、読めない所がある（PCの左の列のラベルなど）。

### 4. Feynの質問の「どこに答えればいいか」が見えない
- Feynの吹き出しは、あいさつ・感想・質問がひと続き。質問の部分が目立たないので、4往復目あたりで何を聞かれているかを探すことになる。
- 自分の吹き出し（青の塗り・白の太字）のほうがFeynより目立っていて、主役が逆。

### 5. 絵文字に頼っている
- 科目（⚡📐🌍⚗️🌿📖🏛️）、全部のボタン（🌙🔄❓📊🔐🚪💡🔍🧮🎤🚀）、納得度の⭐×4、ライフの❤️🖤、🔥💎、結果の🎉📈🔍📝。
- 端末によって絵柄が違い、ダークモードでは黒いハート（🖤）が見えない。Feynのアイコンも科目の絵文字（⚡）で、Feynらしさがない。

### 6. スマホで会話の場所が狭い
- 上に「科目の列」「使い方・マイページ・ログアウトの列」「Feyn・納得度の列」の3段（約130px）が並び、下に「ヒントの列」と入力欄（約120px）。812pxの画面で会話に使えるのは半分強。
- 入力欄が狭く、置き換え文「Feynに解説を入力してください...」が2行に折れて切れている。送信ボタンは「🚀送信」で、数式（🧮）・音声（🎤）と見た目の重さが同じ。
- ニックネーム・試験の種類・やり直す・ダークモードは、スマホでは表示されず、変えられない。

### 7. PCで会話が窮屈・左に余白
- 左に2列（サイドバー200px＋キャラのパネル260px）。キャラのパネルはFeynの名前・バッジ・納得度・⭐・クリア回数だけで、下半分は空いている。
- 吹き出しは最大75%幅で、1280pxの画面でも1行が長すぎたり短すぎたりする（会話の列に読みやすい幅の上限がない）。

### 8. 納得度バーとライフ
- 納得度バーは細く、科目の色で塗られ、キラキラが流れ続ける（常に動いている）。⭐×4と数字が別々の所にあり、スマホでは⭐が消える。
- ライフ（❤️🖤／👑 無制限）は小さな丸い枠の中の絵文字で、残りいくつかが一目で読めない。

### 9. ダークモード
- GitHub風の青黒（`#0D1117`・`#161B22`）。LPのダークモードは「夜の黒板」（緑がかった黒）なので、LPからアプリに入ると色が変わる。
- ヒントの吹き出しが茶色の地に黄色の文字になり、重い。

### 10. クリアの演出
- 6色の紙吹雪（130枚）が4.5秒降る。画面の色とは関係のない色で、「動きを減らす」設定でも降る。
- 結果の画面は、🎉と、黄・オレンジ・緑の色分けで、ほかの画面と雰囲気が違う。

## 直し方の方針（`docs/DESIGN.md` に従う）

| 原因 | 直し方 |
|---|---|
| 色が多い・科目の青で塗る | 色はDESIGNのトークンだけ。科目の色は「科目名の横の小さな点」だけに使い、面は塗らない。Feynの緑はアイコンと納得度だけ。赤は「Feynの質問の印」と「送信ボタン」だけ |
| 何もかも浮いている | 立体の影をやめ、枠は 1px の罫線に。影は「重なり」（結果の画面・メニュー）と「判子」（送信ボタン）だけ。角は 4／6／12／丸 の段 |
| 文字に強弱がない | 吹き出しの本文は 16px・500（ふつうの太さ）。太字はラベルと見出しだけ。補足の文字は `--ink-soft`（7:1以上） |
| 質問が見えない | Feynの吹き出しの「最後の質問の文」に赤ペンの下線（蛍光ペン風）。Feynの吹き出しは白い紙＋罫線の枠、自分の吹き出しはノートの淡い青。LINEと同じく相手は左・自分は右 |
| 絵文字 | ボタン・科目・納得度・ライフの絵文字を、線のアイコン（SVG）と文字に。Feynのアイコンは、LPと同じ緑の丸に角帽のマーク |
| スマホが狭い | 上を「科目の列＋メニューのボタン」の1段と、「Feyn・納得度・ライフ」の細い1段にまとめる。使い方・マイページ・設定・ダークモードはメニューの中に（スマホでも設定を変えられるようにする）。ヒント・答えを見るは入力欄の上に小さく。入力欄は画面の下に固定して広く、ボタンは44px以上 |
| PCが窮屈 | キャラのパネルをやめ、納得度・ライフは会話の列の上の「欄外」に。サイドバーは1列（科目・設定・きろく・メニュー）。会話の列は最大 760px で中央に |
| 納得度・ライフ | 納得度は「ノートの欄外」に置いた細いバー＋25%ごとの目盛り（⭐の代わり）＋数字。100%で緑に。ライフは「残り 2 / 3」と文字で、丸い印を3つ並べる。キラキラは止める |
| ダークモード | LPと同じ「夜の黒板」のトークン |
| クリアの演出 | 紙吹雪の色をDESIGNの色（赤・緑・黄・墨）に絞って短く（1.6秒）し、赤ペンの「納得！」の判子を押す。「動きを減らす」設定の人には出さない（結果の画面はそのまま出る） |

### 変えないもの
- APIの呼び出し・チャットの流れ・DB（`script.js` のロジックは触らず、見た目を作る関数だけ直す）
- 納得度バー・ライフ・ヒント・答えを見る・写真モード・音声入力・数式（LaTeX）・会話の再開・ダークモード・PWA・スマホ対応
- 要素の id と、テストやスクリプトが使っているクラス（`.input-area textarea`・`.send-btn`・`#hintBtn`・`#micBtn` など）
