## 変えたこと

1. **色をLPのトークンだけにした**: `style.css` の直書きの色30種類をなくし、LPと同じトークン（紙・墨・罫線・赤ペン・黒板の緑・Feynの緑・蛍光ペンの黄）に。部品のCSSに色を直接書いていないことをテストで確かめている。
2. **科目の色で塗るのをやめた**: 科目の色は「科目名の横の小さな点」だけ。自分の吹き出し・送信ボタン・納得度バーを科目の色で塗らない。
3. **赤の使い道を2つに**: Feynの質問の印（赤ペンの下線）と、決定のボタン（送信・保存・閉じる・次へ）だけ。
4. **吹き出し**: Feyn（左）は白い紙＋罫線の枠＋角帽のアイコン、自分（右）はノートの淡い青。LINEと同じ左右。本文はふつうの太さの16pxにし、太字は「質問の要点」とラベルだけ。
5. **Feynの質問に赤ペン**: Feynの返事のうち、最後の「？」で終わる文に赤の下線と太字。数式を含む文には付けない（数式の表示を壊さないため）。
6. **立体の影と太い枠をやめた**: 枠は1pxの罫線、角の丸みは 4／6／12px と丸、影は「紙」「重なり」「判子」の3種類だけ。文字の大きさの段は16段 → 9段。
7. **納得度とライフを「欄外」に**: 会話の列の上の細い帯に、Feyn・科目・納得度（25%ごとの目盛りつきの細いバー、100%で「納得！」）・ライフ（丸い印と「1/3」の数字、回復までの時間）を、いつも見える位置にまとめた。キラキラの動きはやめた。
8. **入力欄**: 画面の下に固定。数式・音声・送信は44px以上（48px）。入力欄は書いた量に合わせて伸びる（対応ブラウザ）。ヒント・答えを見るは、入力欄の上に枠なしの控えめなボタンで。置き換え文は「Feynに説明してみよう」。
9. **スマホ**: 上の3段（科目・ユーザー操作・Feyn）を、「ロゴ・科目・メニュー」の1段と、「Feyn・納得度・ライフ」の細い1段に。使い方・マイページ・設定・やり直す・ダークモード・ログアウトはメニューの中に入れた（**これまでスマホで変えられなかったニックネーム・試験の種類・ダークモードも変えられるようになった**）。復習どきの苦手があると、メニューのボタンに赤い点。
10. **PC**: キャラクターのパネル（260pxの列）をやめ、サイドバー1列（科目・きろく・設定・メニュー）＋会話の列に。会話の列は最大760pxで中央に置き、1行が長くなりすぎないようにした。サイドバーは1280×800でスクロールせずに全部見える。
11. **方眼ノートの世界観**: 会話の背景にうっすら方眼。クリアのときは、赤ペンの「納得！」の判子を押し、DESIGNの色だけの紙吹雪を短く（1.8秒）。結果の画面も「納得！」の判子と赤ペンの「理解の穴」に。
12. **ダークモード**: LPと同じ「夜の黒板」の配色に。
13. **絵文字をやめた**: 科目・ボタン・納得度の⭐・ライフの❤️🖤・🔥💎・結果の🎉などを、線のアイコン（SVG）と文字に。アイコンだけのボタンには `aria-label` を付けた。
14. **はみ出し**: 長い文・英単語は折り返し、数式（ブロック）は横スクロール、画像は幅いっぱいまで。
15. **動きを減らす設定**: 判子・紙吹雪・吹き出しが出る動き・考え中の点・マイクの点滅・バーの伸びを止める。
16. **アクセシビリティ**: 補足の文字の色を `#AFAFAF`（白地で約2.3:1）から `--ink-soft`（約7:1）に。フォーカスの輪（赤）を全部のボタン・入力欄に。科目はキーボード（Enter・スペース）でも選べ、選んでいる科目を読み上げに伝える（`aria-current`）。会話の欄は `role="log"`。
17. **見た目以外は変えていない**: APIの呼び出し・会話の流れ・DBはそのまま。`script.js` は、表示を作る関数（吹き出し・ライフ・納得度・結果・紙吹雪・ボタンの文字）と、スマホのメニュー・科目のキーボード操作だけを変更。service worker のキャッシュ名を v3 にして、古いCSS・JSを捨てる。
18. **見た目のバグを1つ直した**: 選択肢や「今回の結果をもう一度見る」を入れた吹き出しの上に、空行が出ていた（組み立て用の改行が表示されていた。改善前からあった）。

### 残した機能（動くことを確認）

## 今回は手を付けなかったが、直したほうがいい所

1. **ほかの画面がまだ古いデザイン**: マイページ・ログイン・先生のダッシュボード・生徒の詳細・特商法・規約のページは、丸ゴシック（M PLUS Rounded 1c）・Duolingo風の緑・GitHub風のダークモードのまま。チャット画面から行き来すると雰囲気が変わる（一覧は `docs/DESIGN.md` の「今のアプリとのずれ」）。特にマイページはチャット画面から一番よく行く画面なので、次に直すならここ。
2. **会話の中の文の絵文字**: エラーの「⚠️」、音声入力のお知らせの「🎤」、写真の確認の文など、`script.js` の文の中に絵文字が少し残っている（音声入力の部分は、テストが中身を使っているので今回は触れなかった）。
3. **選択肢の吹き出しの「答えを確認したね！」など、Feynの言葉づかい**: 見た目は整えたが、文面そのものは見直していない。
4. **アプリの肩書き**: ヘッダーの「物理を教わる生徒役」にそろえたが、AIへの指示（`tutoring.py`）の中のFeynの設定は「ライバル受験生」のまま。会話の中でFeynが自分を「ライバル」と言うことがありうる。
5. **入力欄の高さが伸びるのは対応ブラウザだけ**: `field-sizing: content`（Chrome・Edge の新しい版）。Safari では従来どおり決まった高さ（中はスクロールできる）。
6. **PWAの設定**: `manifest.json` の `theme_color`（緑 `#58CC02`）は変えていない。ホーム画面から開いたときの上のバーの色は、`index.html` の `theme-color`（白／夜の黒板）が使われる端末と、manifest の緑が使われる端末がある。
7. **先生のダッシュボード・生徒の詳細のスマホ表示**: 前回のLPの作業で見つけた横のはみ出し（`docs/lp/LP_IMPROVE_REPORT.md`）は、そのまま。

## 判断に迷って自分で決めたこと

1. **自分の吹き出しの色を、LINEの緑ではなく「ノートの淡い青」にした**。DESIGNで緑は「Feynだけ」、赤は「Feynの質問と決定ボタンだけ」と決めたため。左右の位置・Feynのアイコンの有無・枠の有無で、一目で区別できるようにした。
2. **送信ボタンは赤（決定のボタン）にした**。DESIGNの「赤は決定のボタンに」の決まりどおり。スマホでは幅を取らないよう、矢印のアイコンだけにした（`aria-label="送信"` あり）。
3. **「写真のボタン」は入力欄に足さなかった**。今のアプリでは、写真は「単元を選ぶ」ときの選択肢から送る作りで、写真を送ると新しい会話が始まる。会話の途中の入力欄に置くと、押しただけで今の会話が消えてしまうため。選択肢のボタンは高さ40px以上にした。
4. **質問の印は「最後の『？』の文」だけに付ける**。AIの返事のどこが要点かは文面からは確実に分からないため、Feynのルール（1回の発言で問いは1つ）を頼りに、最後の質問の文にした。数式を含む文は、数式の表示を壊さないよう印を付けない。
5. **PCのキャラクターのパネル（260pxの列）をなくした**。中身（Feynの名前・科目・納得度・ライフ・きろく）はヘッダーとサイドバーに移した。Feynのイラスト（SVG）は、前から非表示だったので、HTMLには残したまま非表示にしている。
6. **PCのサイドバーの「設定」（ニックネーム・試験の種類）を折りたたみにした**。1280×800でサイドバーをスクロールせずにログアウトまで見えるようにするため。一度決めたらあまり変えない項目なので。
7. **レベルの色分け（6色）をやめた**。色を増やさないルールのため。「Lv.2 初学者」の文字は残している。
8. **紙吹雪は残したが、色と時間を絞った**。学習アプリらしい達成感（Duolingo）を残しつつ、DESIGNの色（赤・緑・黄・墨）だけで1.8秒に。主役は赤ペンの「納得！」の判子。
9. **撮影のときは「動きを減らす」設定にした**。演出の途中で写らないように（改善前も同じ条件）。演出そのものは、追加の1枚（`sp-light-clear-moment.png`）で動きありで撮った。
10. **このブランチは master（lp-improve をマージ済み）から作った**。LP（`landing.html`）と撮影スクリプトを使うため。
